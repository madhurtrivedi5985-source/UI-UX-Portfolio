# 🍔 Hot King Burger App

A mobile UI/UX design for a burger ordering app, focused on creating a simple, attractive, and easy-to-use food ordering experience.

## Design Tool

- Figma

## Key Features

- Home screen
- Burger menu
- Product details
- Burger selection
- Cart
- Checkout flow
