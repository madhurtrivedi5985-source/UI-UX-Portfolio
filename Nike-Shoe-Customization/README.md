# Nike Shoe Customization

An interactive Nike shoe customization UI designed in Figma.

## Project Overview

This project allows users to change the shoe design and color with a simple click. The selected shoe design updates instantly, creating a simple and interactive product experience.

## Key Features

- Change shoe design
- Change shoe color
- Interactive prototype
- Simple and clean product UI

## Design Tool

- Figma
