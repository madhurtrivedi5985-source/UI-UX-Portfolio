# PayU Payment App

## Project Overview

A mobile payment app UI/UX design created in Figma, focused on providing a simple, secure, and user-friendly digital payment experience.

## Design Process

### 1. Wireframe
Created wireframes to plan the app structure, screen layout, navigation, and payment flow.

### 2. Mockup
Designed the high-fidelity UI with colors, typography, icons, and reusable components.

### 3. Prototype
Created an interactive Figma prototype to demonstrate the user flow and interactions between screens.

## Key Features

- Simple payment flow
- UPI payment interface
- Transaction history
- Secure payment experience
- Clean and intuitive mobile UI

## Tools Used

- Figma
